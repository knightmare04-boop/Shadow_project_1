\subsection{Architecture}\label{sec:model_arch}
The proposed Hybrid TGN-XGBoost model couples dynamic transactional multigraphs, continuous temporal graph representations, and gradient-boosted decision trees (Fig.~\ref{fig:pipeline_overview}). 

We model the incoming transactional ledger as a directed temporal streaming multigraph:
\begin{equation}
\mathfrak{G} = \left(\mathcal{A},\, \mathcal{X},\, \mathbb{T}\right)
\label{eq:multigraph}
\end{equation}
where $\mathcal{A} = \{\alpha_1, \alpha_2, \dots, \alpha_{|\mathcal{A}|}\}$ denotes the discrete universe of financial ledger accounts or counterparties, and $\mathbb{T} = \{\tau_1, \tau_2, \dots\} \subset \mathbb{N}$ represents strictly ordered epoch posting timestamps ($\tau_k \le \tau_{k+1}$).

Each transactional edge is represented as an ordered quintuple:
\begin{equation}
\xi_k = \left(\mathfrak{s}_k,\, \mathfrak{d}_k,\, \tau_k,\, \nu_k,\, \mathbf{c}_k\right) \in \mathcal{X}
\label{eq:edge_quintuple}
\end{equation}
where $\mathfrak{s}_k \in \mathcal{A}$ is the debiting source entity, $\mathfrak{d}_k \in \mathcal{A}$ is the crediting destination counterparty, $\tau_k \in \mathbb{T}$ is the posting time, $\nu_k \in \mathbb{R}^+$ is the positive monetary volume, and $\mathbf{c}_k \in \mathbb{R}^{d_c}$ encodes categorical voucher metadata.

The architecture comprises six tightly coupled operational modules:
\begin{enumerate}
    \item \textbf{Chronological Ingestion \& Graph Projection}: Sequentially maps continuous transactions to dynamic graph edges under strict time sorting.
    \item \textbf{Streaming Leakage-Free Topology Engine}: Evaluates sliding-window structural metrics solely against historical graph state $\mathfrak{G}_{< \tau_k}$.
    \item \textbf{Continuous Dynamic Graph Representation (TGN)}: Maintains continuous-time node memory states via a Temporal Graph Network.
    \item \textbf{Imbalance-Calibrated Ensemble Classifier (XGBoost)}: Scores transactions via an XGBoost gradient-boosted decision tree head optimized with an $\alpha$-free focal loss.
    \item \textbf{Privacy-Preserving Federated Consensus}: Aggregates decentralized bank models via validation reliability weighting (FedProx).
    \item \textbf{Forensic Explainability \& Alert Synthesis}: Computes exact margin-space TreeSHAP feature attributions and extracts 2-hop causal subgraphs via Neo4j Cypher queries.
\end{enumerate}

\subsection{Preprocessing}\label{sec:model_preproc}
All financial transaction data is processed through a deterministic, strictly causal pipeline:
\begin{enumerate}
    \item \textbf{Type Normalization}: Timestamps are coerced to integer epoch seconds; monetary amounts $\nu_k > 0$ are converted to double-precision floats; categorical metadata are dictionary-encoded with reserved unseen-category indices.
    \item \textbf{Chronological Partitioning}: Transactions are sorted by the composite key $(\tau_k, \text{tx\_id})$. The data is partitioned into strictly ordered chronological splits: 60\% training ($\tau < T_1$), 20\% validation ($T_1 \le \tau < T_2$), and 20\% held-out test ($\tau \ge T_2$). No shuffling or random cross-validation is permitted.
    \item \textbf{Expanding Sequential Estimators}: All feature scaling factors and running z-scores are computed using Welford's algorithm \cite{welford1962note} over the causal historical set $\mathbb{H}_k(\mathfrak{s}_k) = \{j < k : \mathfrak{s}_j = \mathfrak{s}_k\}$ only, preventing lookahead contamination.
\end{enumerate}

\subsection{Feature Analysis}\label{sec:model_features}
Each transaction $\xi_k$ is mapped to a composite feature representation combining tabular indicators, streaming graph topology, and continuous TGN interaction embeddings:
\begin{equation}
\mathbf{\Phi}(\xi_k) = \mathbf{\psi}_{\text{tab}}(\xi_k) \oplus \mathbf{\Omega}_{\text{topo}}\Big(\xi_k,\, \mathfrak{G}_{< \tau_k}^{(W)}\Big) \oplus \mathbf{h}_{\text{dyn}}^{\text{TGN}}\big(\xi_k,\, \tau_k\big) \in \mathbb{R}^D
\label{eq:feature_vector}
\end{equation}
where:
\begin{itemize}
    \item $\mathbf{\psi}_{\text{tab}}(\xi_k)$: Tabular features including $\log_{10}(\nu_k + 1)$, running historical z-score, diurnal periodic harmonics $(\sin(2\pi \hbar_k / 24), \cos(2\pi \hbar_k / 24))$, and inter-event arrival delta $\Delta \tau_k$.
    \item $\mathbf{\Omega}_{\text{topo}}$: Thirteen structural features extracted over trailing windows $W \in \{1\text{d}, 7\text{d}, 30\text{d}\}$: source out-degree, destination in-degree, fan-in ratio, fan-out ratio, counterparty reciprocity, burstiness velocity, amount recurrence count (\texttt{LapMemory}), and directed cycle counts.
    \item $\mathbf{h}_{\text{dyn}}^{\text{TGN}}$: 16-dimensional continuous-time latent representations produced by a Temporal Graph Network \cite{rossi2020temporal}, encoding dynamic counterparty velocity shifts.
\end{itemize}

\textbf{The Read-Then-Insert Execution Invariant}:
To guarantee zero lookahead leakage, the engine evaluates topology strictly against the trailing causal subgraph $\mathfrak{G}_{< \tau_k}^{(W)} = \{ \xi_j \in \mathcal{X} : \tau_k - W \le \tau_j < \tau_k \}$, enforcing:
\begin{equation}
\forall \xi_j \in \mathfrak{G}_{< \tau_k}^{(W)}, \quad \tau_j < \tau_k \quad \Longrightarrow \quad \xi_k \notin \mathfrak{G}_{< \tau_k}^{(W)}
\label{eq:leakage_invariant}
\end{equation}
Graph queries read historical state before edge $\xi_k$ is added to the graph.

\subsection{Classification}\label{sec:model_class}
The proposed TGN-XGBoost champion model couples the composite representation with gradient-boosted decision trees \cite{chen2016xgboost}:
\begin{equation}
f_{\text{TGN-XGBoost}}(\xi_k) = \mathcal{T}_{\text{GBDT}}\Big(\mathbf{\Phi}(\xi_k);\, \mathcal{J}_{\text{focal}},\, \Theta^*\Big)
\label{eq:champion_model}
\end{equation}
optimized under an unweighted, symmetric $\alpha$-free focal loss \cite{lin2017focal}:
\begin{equation}
\mathcal{J}_{\text{focal}}(\hat{\pi}_k, y_k) = - y_k \left(1 - \hat{\pi}_k\right)^\gamma \ln\left(\hat{\pi}_k\right) - (1 - y_k) \hat{\pi}_k^\gamma \ln\left(1 - \hat{\pi}_k\right)
\label{eq:focal_objective}
\end{equation}
where $\hat{\pi}_k = \sigma(\theta_k)$ is the sigmoid posterior of predicted log-odds margin $\theta_k \in \mathbb{R}$, $y_k \in \{0, 1\}$ is the forensic label, and $\gamma \in \mathbb{R}^+$ is the focusing factor ($\gamma = 1.0$ for BankSim, $\gamma = 2.0$ for SAP W{\"u}rzburg). Decision thresholds $\theta_{\text{audit}}^*$ are tuned strictly on validation splits and frozen for test evaluation.

\subsection{Federated Learning Architecture}\label{sec:model_federated}
To overcome cross-institutional banking privacy barriers (GDPR, GLBA), we deploy a Score-Level Ensemble Consensus architecture across $C=4$ heterogeneous institutional clients. Rather than uniform averaging (FedAvg) \cite{mcmahan2017communication}, our server implements empirical validation reliability weighting (FedProx) \cite{li2020federated}:
\begin{equation}
\varpi_c = \frac{\left(\mathcal{P}_{\text{val}}^{(c)}\right)^\kappa}{\sum_{m=1}^C \left(\mathcal{P}_{\text{val}}^{(m)}\right)^\kappa}, \quad \hat{\Pi}_{\text{consensus}}(\xi_k) = \sum_{c=1}^C \varpi_c \cdot \mathcal{M}^{(c)}\left(\mathbf{\Phi}(\xi_k)\right)
\label{eq:fed_consensus}
\end{equation}
where $\mathcal{P}_{\text{val}}^{(c)} = \text{PR-AUC}(\mathcal{D}_{\text{val}}^{(c)})$ and $\kappa \ge 1.0$.

\subsection{Explainable AI and Forensic Synthesis}\label{sec:model_xai}
Regulatory compliance requires verifiable evidence trails \cite{faccia2026xaiauditing,uddin2026shapley}. Feature attributions are computed via exact TreeSHAP \cite{lundberg2020treeshap} in log-odds margin space:
\begin{equation}
\theta_k = \ln\left(\frac{\hat{\pi}_k}{1 - \hat{\pi}_k}\right) = \Lambda_0 + \sum_{d=1}^D \Lambda_d\Big(\mathbf{\Phi}(\xi_k)\Big)
\label{eq:treeshap_additivity}
\end{equation}
When a score exceeds $\theta_{\text{audit}}^*$, the system synthesizes a two-layer forensic alert packet containing the top-3 margin-space drivers and a deterministic Neo4j 2-hop causal subgraph.
